# UI Specification

## Design Principles

- Clean modern UI
- Mobile-first responsive design
- Focus on readability
- Card-based layouts

---

## Layout

### Navbar

Contains:

- App logo
- Search bar
- Add recipe button

---

### Homepage

Sections:

Navbar

Recipe Grid

Recipe cards showing:

- Recipe image
- Title
- Cooking time
- Short description

### Recipe Details Page

Top section:

Recipe image
Recipe title
Cooking time

Sections:

Ingredients list
Cooking steps

Actions:

Edit recipe
Delete recipe

---

### Add Recipe Page

Form fields:

Title
Description
Cooking Time
Ingredients (dynamic list)
Steps (dynamic list)
Image URL

Submit button
